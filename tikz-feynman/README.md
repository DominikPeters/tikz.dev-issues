# TikZ-Feynman manual

The lwarp build of [TikZ-Feynman](https://github.com/JP-Ellis/tikz-feynman)
for `tikz.dev/tikz-feynman/`, using the shared PGF documentation helpers and
contributed manual page processor.

From the repository root:

```bash
scripts/fetch.sh tikz-feynman
scripts/build.sh tikz-feynman
python3 -m http.server --directory build/tikz-feynman/site 8765
```

Requires the same tools as [tikz-cd](../tikz-cd/README.md), plus Biber and the
upstream font/bibliography packages (EB Garamond, Inconsolata, newtxmath,
biblatex-phys). The shared TeX Live CI image supplies them. LuaLaTeX is required
for automatic graph placement. Package code comes from the pinned upstream
checkout; other manuals need not be built first.

The patch loads lwarp, assigns stable page names, uses the installed Inconsolata
font filename, and replaces print-only contents/example formatting. One inline
verbatim phrase is joined across a source line break. Two displayed equations
containing diagrams are rendered whole as illustrations so the baseline
comparison remains faithful. The 69 codeexample blocks remain unchanged.
The local HTML style makes metavariables safe in index entries and gives the
command/key index a filename distinct from the cover page.
It also expands bibliography URL fields before lwarp writes the links,
preserving the DOI and arXiv destinations generated by biblatex-phys.

Illustrations use the shared persistent conversion cache and SVG/PNG selection
after SVGO. The page processor adds navigation, code copying, permalinks,
image dimensions and reference validation. The index and bibliography have
their own pages. The lock participates in the normal build, upstream-watch
and deployment workflows.
